      CN6000 Python NLP Pipeline

      How SkillAlign Evaluates Resume-to-Job Alignment

      Every resume scan passes through four deterministic Python stages—combining PyMuPDF / python-docx extraction, spaCy skill matching, and scikit-learn TF-IDF cosine similarity.

      Stage 01

      Document Ingestion & Text Extraction

      Uses PyMuPDF for PDF resumes and python-docx for Word paragraphs and tables, stripping binary formatting noise cleanly in memory.

      Supports .pdf and .docx up to 5MB

      Stage 02

      spaCy Tokenization & Lemmatization

      Processes text with spaCy (en_core_web_sm), normalizing word forms, filtering stop words, and preserving multi-symbol technical identifiers like C++, C#, and CI/CD.

      spaCy linguistic preprocessing

      Stage 03

      spaCy PhraseMatcher Skill Extraction

      Resolves skill aliases (e.g., ReactJS → React, sklearn → scikit-learn, Postgres → PostgreSQL) across both documents to compute Matched and Missing Skills.

      Canonical competency matching

      Stage 04

      scikit-learn TF-IDF & Cosine Similarity

      Builds sublinear unigram/bigram TF-IDF vectors with scikit-learn and blends 65% skill coverage with 35% cosine similarity into an interpretable 0–100% score.

      Deterministic scikit-learn scoring

      SkillAlign — CN6000 Resume-to-Job Matching System

      SkillAlign is built with Python 3, Flask, spaCy, scikit-learn, PyMuPDF, and python-docx. It evaluates candidate resumes directly against target job descriptions without user accounts, external databases, or unrelated job-search clutter.

      Real Document Parsing

      PyMuPDF and python-docx extract clean text from PDF and Word resumes up to 5MB.

      Focused Academic Scope

      Dedicated strictly to resume scanning, skill matching, and actionable gap insights.
