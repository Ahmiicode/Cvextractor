Core Capabilities

Built for transparent, accurate resume evaluation

Every score is computed directly by Python, spaCy, and scikit-learn from your uploaded document and target job description.

01. PDF & DOCX Parsing

Extracts clean body and table text from multi-page PDF and Word documents using PyMuPDF and python-docx.

Supports .pdf & .docx up to 5MB

02. spaCy Skill Extraction

Lemmatizes text and matches technical aliases (such as ReactJS, sklearn, and Postgres) into canonical competencies.

spaCy PhraseMatcher pipeline

03. TF-IDF Vector Scoring

Constructs unigram and bigram TF-IDF matrices with scikit-learn to measure exact cosine similarity between documents.

Deterministic similarity math

04. Actionable Gap Insights

Separates matched competencies from missing target skills and delivers tailored recommendations to improve alignment.

About the Project

Designed for the CN6000 Resume-to-Job Matching System

SkillAlign pairs Python NLP engineering with a modern SaaS analytics dashboard. Rather than leaving candidates guessing why an application passes or fails screening, the system breaks alignment into measurable skill coverage and TF-IDF similarity.

Focused Academic Scope: Built exclusively for resume parsing, skill matching, and gap diagnostics without account walls or job boards.

In-Memory Document Processing: Uploaded resumes are parsed in memory via PyMuPDF and python-docx and never persisted in external profiles.

Reproducible Scoring: Combines 65% structured skill coverage with 35% scikit-learn TF-IDF cosine similarity.
